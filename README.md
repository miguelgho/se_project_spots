# 📸 Spots - An Image Sharing Platform

Spots is a responsive web application that allows users to share, view, and interact with images. This project demonstrates core front-end development skills and has been **refactored to use Webpack** for modular component-based development.

**[Live Demo Link](https://miguelgho.github.io/se_project_spots/)**

---

## ✨ Key Features

- **Edit Profile:** Users can update their name and professional description via a pop-up modal.
- **Add New Posts:** Users can add new images to the gallery by providing a title and a URL.
- **Delete Posts:** Users can remove their own images from the gallery.
- **Image Interaction:** Users can 'like' their favorite images.
- **Robust Form Validation:** All forms feature real-time, client-side validation to guide the user.
- **Improved Modal UX:** Modals close via the 'X' button, the "Escape" key, or by clicking the overlay.
- **Responsive Design:** Fully responsive layout optimized for desktop, tablet, and mobile.

---

## 🛠 Tech Stack

- **HTML5:** Semantic markup.
- **CSS3:** Custom styling with Flexbox and Grid.
- **JavaScript (ES6+):** Modular architecture with `import`/`export` syntax.
- **Webpack:** Module bundling, asset management (images/fonts), and minification.
- **Babel:** Transpiling for cross-browser compatibility (ES5 support).
- **PostCSS:** Automated vendor prefixing and CSS optimization.
- **NPM:** Package and dependency management.

## 💻 Running Locally

Since this project uses Webpack, you will need Node.js installed to run it.

### 1. Clone the repository

```bash
git clone [https://github.com/miguelgho/se_project_spots.git](https://github.com/miguelgho/se_project_spots.git)
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The project will open at localhost:8080 with hot reloading enabled.

### 4. Build for production

```bash
npm run build
```

This creates the optimized dist/ folder.
